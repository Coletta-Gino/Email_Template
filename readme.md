# Email Template

This repository contains a customizable email template designed for use in marketing campaigns and transactional emails. The template includes both **light mode and dark mode** variations, aligning with XiaoDev's branding.

## Introduction
The **Email Template** is designed to provide a responsive and adaptable structure for **email marketing campaigns** and **transactional emails**. It follows modern email standards to ensure compatibility across different email clients.

## Features
- **Light and Dark Mode**: Includes two variations to match different branding requirements.
- **Responsive Design**: Ensures proper rendering on desktop and mobile devices.
- **Customizable Layout**: Can be modified to fit various content structures.
- **Cross-Client Compatibility**: Works across major email clients including Gmail, Outlook, and Apple Mail.

## Technologies Used
- **HTML**: Structure of the email.
- **CSS (Inline Styles)**: Styling for consistent rendering in email clients.
- **Media Queries**: Adjusts styles for mobile-friendly layouts.

## Installation
1. Clone this repository to your local machine.
2. Open `index.html` in a text editor.
3. Modify the template content to fit your needs.
4. Use an email testing tool (like Litmus or Mailtrap) to preview rendering.
5. Deploy through an **email marketing platform** (Mailchimp, SendGrid, etc.).

## Usage
- Open `index.html` in a browser to preview the email design.
- Modify text and images as needed.
- Ensure inline styles remain intact for consistent display across email clients.
- Send a test email to verify rendering before distribution.
